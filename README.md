 🍽️ Smart Food Ordering App

 📖 Overview
The Smart Food Ordering App is a Kotlin-based Android application that allows users to browse menus, place food orders, and make payments conveniently. The system also provides an admin panel for managing menus and tracking orders.

 🚀 Features
- Browse menu items and categories  
- Add items to cart and checkout  
- Secure OTP-based order confirmation  
- Admin dashboard for menu and order management  
- Firebase integration for data storage  

 🧰 
- Language: Kotlin  
- Framework: Android Studio (Jetpack Compose)  
- Database: Firebase  
- Version Control: GitHub
